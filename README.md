# AllLogic

Repositório central da AllLogic Online.

Este repositório mantém documentos e informações de caráter geral da organização que não pertencem exclusivamente ao SGA, ao site institucional ou a um projeto específico.

## Estrutura da organização

A estrutura de diretórios da AllLogic Online é:

- `AGENTS.md` — instruções gerais para Agentes de IA.
- `SGA/` — Sistema de Gestão AllLogic.
- `Site/` — projeto do site institucional.
- `Projetos/` — projetos e soluções da AllLogic Online.

Os diretórios `SGA/`, `Site/` e `Projetos/` contêm repositórios independentes e não fazem parte do histórico Git deste repositório central.

## Repositório central

O repositório central existe para versionar os elementos comuns à organização, preservando a independência dos demais projetos e repositórios.

Documentação institucional, técnica e operacional deve permanecer no SGA quando esse for seu escopo.

## Referência principal

- `AGENTS.md` — instruções gerais para Agentes de IA autorizados a trabalhar na estrutura da AllLogic Online.
